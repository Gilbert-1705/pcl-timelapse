# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest release | Yes |
| older versions | No |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting instead:
**Security → Report a vulnerability** in this repository.

Do not include real credentials (camera user/password, Prusa Connect API
tokens), personal data, camera images of your home, unfiltered server logs or
details about your home network in a report.
